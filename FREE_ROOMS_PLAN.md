# План реализации функции «Свободные аудитории» (Free Rooms) без Supabase

## Контекст и архитектурный анализ
В официальном репозитории (ветка `master`) авторы внедрили экран «Свободные аудитории», однако жестко привязали его к закрытому бэкенду Supabase:
1. Запросы выполняются через приватную RPC-функцию `supabase.rpc('get_free_rooms')`.
2. Функция доступна только авторизованным пользователям (`authenticated`).
3. Серверная база данных наполняется утилитой `tools/schedule_fetcher`, выгружающей iCal-расписания из API МИРЭА (`schedule-of.mirea.ru`).

Поскольку у самого API МИРЭА нет прямого эндпоинта «список свободных аудиторий на текущую минуту», опрашивать сотни аудиторий непосредственно с мобильного телефона неэффективно (высокий расход трафика, батареи и риск попасть под IP-rate limit).

---

## Архитектура решения: Serverless Cron + GitHub CDN

### 1. Бэкенд на GitHub Actions (`.github/workflows/sync-free-rooms.yml`)
* **Триггер**: Регулярный запуск по Cron (например, каждый день в 05:00 и 12:00 МСК) + ручной запуск `workflow_dispatch`.
* **Скрипт синхронизации** (`tools/free_rooms_builder`):
  * Адаптация логики `tools/schedule_fetcher`:
    * Использование проверенных таймаутов, очередей и заголовков (`RetryingSourceClient`).
    * Конкурентность запросов (concurrency: 8-12, batch-size: 8) с экспоненциальным backoff для предотвращения блокировок со стороны `schedule-of.mirea.ru`.
  * Получение списка всех аудиторий МИРЭА по кампусам (В-78, С-20, МП-1, СГ-22 и др.).
  * Загрузка расписаний занятий на текущий день/неделю.
  * Расчет свободных окон для каждого кабинета (исключая дистанционные/СДО пары).
* **Публикация артефакта**:
  * Генерация компактного JSON (`free_rooms.json`, ~100–150 КБ).
  * Автоматический коммит файла в ветку `gh-pages` (или в GitHub Releases).
  * Прямой доступ по публичному URL:
    `https://raw.githubusercontent.com/l1ratch/university-app/gh-pages/free_rooms.json`

### 2. Формат данных `free_rooms.json` (100% совместим с моделями master)
```json
[
  {
    "room": "И-212-г",
    "campus": "В-78",
    "busyIntervals": [
      { "start": "09:00", "end": "10:30" },
      { "start": "10:40", "12:10" }
    ],
    "freeUntil": "2026-09-05T14:20:00+03:00"
  },
  {
    "room": "А-110",
    "campus": "В-78",
    "busyIntervals": [],
    "freeUntil": null
  }
]
```

### 3. Интеграция в мобильное приложение (версия 1.5.13)
* **UI**: Перенос готового экрана `FreeRoomsPage` / `FreeRoomsView` из `master`:
  * Фильтрация по кампусам.
  * Статусы: «Свободно сейчас», «Свободно до …», «Занято».
  * Поиск по номеру аудитории.
* **Слой данных (`FreeRoomsRepository`)**:
  * Замена вызова `supabase.rpc('get_free_rooms')` на быстрый HTTP GET к GitHub JSON.
  * Локальное кэширование на телефоне через `shared_preferences` / `hydrated_bloc` (чтобы страница открывалась мгновенно даже в офлайне).

## Преимущества решения
1. **Полная независимость**: Нет зависимости от чужих учетных записей Supabase и платных серверов.
2. **Безопасность API**: Запросы к серверам МИРЭА идут только с раннеров GitHub Actions раз в сутки по отлаженным алгоритмам авторов.
3. **Скорость**: Для телефона загрузка одного сжатого JSON занимает менее 0.3 секунды.
4. **Оригинальный интерфейс**: Внешний вид и поведение полностью соответствуют последней версии приложения.
