# Справочник кодов ошибок приложения «Расписание МИРЭА»

В приложении используется краткая система кодов ошибок для экономии места на экране мобильных устройств и быстрого выявления причин неполадок.

| Код | Краткое название | Описание | Причина | Что делать |
|---|---|---|---|---|
| **E-101** | Нет сети | Отсутствует подключение к интернету | Устройство не подключено к Wi-Fi или сотовой сети | Проверьте подключение к сети; приложение использует сохраненный офлайн-кэш |
| **E-102** | Таймаут | Превышено время ожидания ответа | Сервер расписания МИРЭА отвечает слишком медленно | Повторите попытку через пару минут |
| **E-103** | Сбой сервера | Внутренняя ошибка сервера (HTTP 5xx) | Технические работы или перегрузка серверов РТУ МИРЭА | Дождитесь завершения технических работ на стороне университета |
| **E-104** | Не найдено | Расписание не найдено (HTTP 404) | Указанная группа, аудитория или преподаватель отсутствуют в базе | Проверьте правильность выбранной группы в поиске |
| **E-105** | Ошибка парсинга | Сбой разбора формата расписания | Изменился формат календаря iCal API МИРЭА | Обновите приложение до последней версии или сообщите в Issues |
| **E-201** | Ошибка кэша | Не удалось прочитать локальный кэш | Повреждение данных в хранилище устройства | Очистите кэш в меню «Настройки -> Данные и память» |
| **E-202** | Сбой записи | Не удалось сохранить данные в кэш | Недостаточно свободного места на устройстве | Освободите память на устройстве |
| **E-301** | Сбой обновления | Ошибка проверки релизов на GitHub | Превышен лимит запросов GitHub API или нет доступа | Проверьте доступность github.com |
| **E-999** | Непредвиденная ошибка | Произошла неизвестная ошибка | Неучтенное исключение в процессе выполнения | Сообщите об ошибке разработчику: [GitHub Issues](https://github.com/l1ratch/MIREA-Schedule/issues) |

---
*При возникновении проблем, которых нет в таблице, вы можете открыть Issue в репозитории [l1ratch/MIREA-Schedule](https://github.com/l1ratch/MIREA-Schedule).*
